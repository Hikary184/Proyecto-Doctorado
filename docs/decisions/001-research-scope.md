# Research Scope Decision 001

## Date

September 2026

## Decision

The core doctoral research will focus on linguistic
information retrieval for low-resource Indigenous
languages.

## Core research components

- lexical normalization
- automatic morphological analysis
- phonological similarity using textual/IPA representations
- semantic retrieval
- hybrid information retrieval

## Removed from the core scope

- Automatic Speech Recognition
- Forced Alignment

## Community participation

Community participation may be incorporated as a validation
component but is not considered a mandatory computational
research objective.

## Backend

Python and FastAPI will be used for the research backend.
