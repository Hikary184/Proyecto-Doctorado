# Indigenous Dictionary Retrieval

Doctoral research project focused on linguistic information
retrieval for digital talking dictionaries of low-resource
Indigenous languages.

## Research objectives

The project investigates the integration of:

- lexical normalization
- morphological analysis
- phonological similarity
- multilingual semantic representations
- hybrid information retrieval
- evaluation methodologies for low-resource languages

## Research architecture

The system is designed as a modular research framework
implemented primarily in Python.

The principal experimental components are:

1. lexical retrieval
2. morphological retrieval
3. phonological retrieval
4. semantic retrieval
5. hybrid retrieval
